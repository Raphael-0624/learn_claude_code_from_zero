Claude Code 的核心基础设施层——AI Agent 与真实世界之间的操作系统。理解 Harness，就是理解 Claude 如何感知和操作环境。

什么是 Harness？

Harness（内部代号：Tengu）是 Claude Code 的执行引擎，位于 Claude LLM 与真实计算环境之间。它不是一个单一组件，而是一套完整的基础设施层。

权限控制系统

🚫 Layer 1: Always Deny（永远拒绝）

  • 删除系统文件（rm -rf /）
  • 修改 /etc、/sys 等系统目录
  • 访问其他用户的私有数据
  • 执行已知危险命令

✅ Layer 2: Always Allow（永远允许）

  • 读取项目文件（read, grep, glob）
  • 查看 git 状态（git_status, git_diff）
  • 搜索代码库（search_files）
  • 查看系统信息（ls, pwd, env）

⚠️ Layer 3: User-Gated（用户审批）

  • 写入/修改文件（write, edit）
  • 执行命令（bash, python）
  • 网络请求（web_fetch, http_request）
  • 安装依赖（npm install）

权限配置文件

// .claude/settings.json
{
  "permissions": {
    "allow": [
      "bash(npm test)",
      "bash(git *)",
      "read(*)",
      "write(src/**)"
    ],
    "deny": [
      "bash(rm -rf *)",
      "bash(sudo *)",
      "write(/etc/**)"
    ]
  }
}

Programmatic Tool Calling（PTC）

PTC 允许 Claude 编写代码来编排多个工具调用，而不是逐个调用工具，大幅减少延迟和 token 消耗。

❌ 传统方式（逐个调用）

调用 1: read("src/main.py")
等待结果...
调用 2: read("src/utils.py")
等待结果...
调用 3: grep("TODO", "src/")
等待结果...
调用 4: write("report.md", ...)
4次往返 · 高延迟 · 高 token

✅ PTC 方式（编程式编排）

files = [read(f) for f in glob("src/**")]
todos = grep("TODO", files)
write("report.md", format(todos))
-
-
-
-
1次往返 · 低延迟 · 节省 40-60%

会话状态管理

状态存储结构

~/.claude/
├── sessions/
│   ├── <session-id>/
│   │   ├── context.json      # 当前上下文快照
│   │   ├── tool_history.json # 工具调用历史
│   │   └── checkpoints/      # 自动检查点
│   └── ...
├── settings.json             # 全局配置
└── MEMORY.md                 # 跨会话记忆

自动检查点触发条件

📝

写入文件前

在修改任何文件之前自动创建检查点，支持回滚

💥

破坏性命令前

执行可能影响系统状态的命令前保存快照

🗜️

上下文压缩前

压缩上下文前保存完整状态，防止信息丢失

⏰

会话超时前

会话即将超时时自动保存，支持下次恢复

# 检查点管理命令
claude --list-checkpoints    # 查看所有检查点
claude --resume cp_002       # 恢复到特定检查点
claude --resume latest       # 恢复到最近检查点

Harness 与 Agent Loop 的关系

Agent Loop（高层调度） │ ├── Think: Claude 分析情况，决定下一步 │ ├── Act: 向 Harness 发送工具调用请求 │ │ │ ├── Harness 权限检查 │ ├── Harness 沙箱执行 │ └── Harness 返回结果 │ ├── Observe: Claude 接收 Harness 返回的结果 │ └── Decide: 继续循环 or 完成任务
💡 关键理解：Harness 是 Agent Loop 的执行层，Agent Loop 是 Harness 的调用者。两者共同构成 Claude Code 的核心运行机制。Harness 不做决策，只负责安全地执行决策。

最佳实践

权限最小化原则

❌ 不推荐：过于宽泛

"allow": ["bash(*)", "write(**)"]
任何命令都可以执行
任何文件都可以修改
安全风险极高

✅ 推荐：精确指定

"allow": ["bash(npm test)"]
"allow": ["bash(npm run lint)"]
"allow": ["write(src/**/*.ts)"]
安全可控，最小权限
⚠️ CI/CD 注意：在 CI/CD 环境中使用 --dangerously-skip-permissions 时，请确保在受控环境中运行，并配置严格的 deny 规则防止意外操作。
