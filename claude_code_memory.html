Auto Dream：后台记忆整合机制

Auto Dream 是 Claude Code 最神秘的特性——一个在后台运行的记忆整合机制，类比人脑在睡眠时处理和整合记忆。

🧠 人脑睡眠记忆处理

→白天积累经验
→睡眠时整合记忆
→剪枝无用记忆
→强化重要记忆
→重构记忆结构

🤖 Claude Auto Dream

→会话积累记忆
→后台触发整合
→删除过时条目
→合并相关信息
→优化索引结构

触发条件

⏰

时间条件

距上次整合超过 24 小时自动触发

📊

会话数量

累计 5 个会话后触发整合

📦

文件大小

记忆文件超过阈值时触发

👆

手动触发

用户执行 claude /dream 命令

三个核心操作

✂️

剪枝（Pruning）

删除过时信息、已解决的 bug、废弃的 API 记录，移除重复条目

🔗

合并（Merging）

将相关信息整合到同一主题，消除矛盾记录，更新过时信息

🏗️

重构（Restructuring）

优化 MEMORY.md 索引结构，将频繁访问的信息移到前面

⚠️ 重要限制：Auto Dream 只能修改 ~/.claude/memories/ 目录下的记忆文件，不能修改任何项目源代码，不能执行命令，不能访问网络。 
# Auto Dream 管理命令
claude /dream              # 手动触发记忆整合
claude /dream --log        # 查看整合日志
claude /dream --dry-run    # 预览（不实际执行）

# 禁用 Auto Dream（~/.claude/settings.json）
{
  "autoDream": { "enabled": false }
}
