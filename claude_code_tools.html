💡 并行调用：Claude 可以在一次响应中发出多个工具调用请求，Harness 会并行执行它们，大幅减少总延迟。

🎨
Figma
设计, 组件
📊
Google Drive
文件, 表格
⚡
Zapier
6000+ 应用
// .claude/mcp.json 配置示例
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_TOKEN": "${GITHUB_TOKEN}" }
    },
    "slack": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-slack"],
      "env": { "SLACK_BOT_TOKEN": "${SLACK_BOT_TOKEN}" }
    }
  }
}

# 部署技能

## 描述
自动化部署流程，包含构建、测试、部署三个阶段

## 步骤
1. 运行测试：`npm test`
2. 构建项目：`npm run build`
3. 上传到 S3：`aws s3 sync dist/ s3://my-bucket/`
4. 清除 CDN 缓存：`aws cloudfront create-invalidation ...`

## 回滚方案
如果部署失败，执行：`aws s3 sync s3://backup/ s3://my-bucket/`

最佳实践

🎯

先搜索，再读取

用 grep 定位目标代码，再精确读取，避免加载整个目录浪费 token

⚡

利用并行调用

明确告诉 Claude 并行处理多个文件，减少总执行时间

🔐

最小权限原则

在 settings.json 中精确指定允许的操作，避免过于宽泛的权限

🔌

善用 MCP 扩展

将常用的外部服务通过 MCP 接入，让 Claude 直接操作 GitHub、Slack 等
